# AI Agent Harness 任务分组 · 2.3.1

可复用的中文技能包：识别当前宿主与设备，先提分类方案并取得确认，再通过该应用真实支持的原生方式归组；不支持时只生成建议。

- Codex、WorkBuddy 或其他 Harness 分别核验，互不套用接口/数据库
- 根据当前设备的实际任务形成最少必要分类，适合的现有分类优先复用；首次确认组名、数量与规则，可选一次授权范围明确的后续自动维护
- 按实际用户请求、关键交付和主题变化命名已有会话；已准确的标题保留
- 本批运行中的会话结束后补命名，固定队列不扩展未来新会话；外部改名保留，全部处理完停用专用跟进
- 可选自动标题：保护手动命名/锁定，真正支持事件时随使用触发，不需每周单独安排
- 保护手动标题、现有组、活跃会话和历史；执行前后核对并准备回退
- WorkBuddy 故障诊断独立处理，不自动 selfheal

## 项目、工作空间与分组

Codex 的项目关联实际工作目录，侧边栏分组用于查找对话；移动已有对话到分组不自动改变项目或目录。WorkBuddy 的工作空间按真实目录汇总任务，显示名与路径分开核对；更换目录可能影响任务执行，不能用业务分类强行迁移研究项目。详细区别仅放在匹配产品分支。

用户已明确指定已有组的合并等具体操作时，复用该项授权，不重复询问同一事项；超出的项目、目录、标题或账户变更仍须另行核对。已有维护入口可按已授权范围调用本技能，不因接入而另建调度。

## 维护来源

将本仓库作为方法来源时，部署副本记录所用提交，修改在同一任务内同步到仓库的可审阅分支并读回。贡献、测试及同步要求见 [贡献说明](CONTRIBUTING.md)。设备状态和真实会话清单不进入公开仓库。

## 使用
将完整 `group-agent-tasks` 文件夹按**目标应用当前官方方法**加载。安装或加载本包不会安装启动项、修改真实应用或启动 Codex 任务；没有统一安装路径，也不保证所有宿主都支持技能加载。

可直接要求：“先识别当前应用和能力，再给我的任务提出分组方案，等我确认后再执行。”

也可要求：“保留当前分组，把这批已停止会话按实际内容命名；正在运行的等业务结束后再命名。”明确的本批改名授权无需反复批准每个标题；如果要求先看方案，则先确认后执行。细节见 [会话内容命名](references/content-titles.md)。

离线示例（Python 3.8+，仅标准库，在包目录运行）：

```sh
python scripts/plan_preview.py examples/inventory.json examples/proposal.json
python scripts/upkeep_guard.py examples/upkeep.json --html > upkeep-review.html
python -m unittest discover -s tests -v
```

以上两个离线脚本输出到标准输出，不访问网络、不读取应用目录、不修改输入、不执行归组或标题写入。实际分类和标题执行由加载技能的 Agent 使用当前已核实的原生工具/UI完成。

## 可选：Codex 自定义分组按活动上移

某个已验证 Windows Codex desktop 版本的自定义分组保存手动位置，通用“最近更新”排序没有覆盖组内。用户明确要求持续按聊天活动上移时，可选择 [Codex 活动排序适配器](references/codex-recency.md)。它保留现有组和归属，只对本地 Codex 会话执行同组顶部移动。

适配器默认不执行；本机配置、真实执行器环境、当前原生能力和持续授权齐备后才通过 `start.ps1` 显式启动。每3秒读取活动元数据；侧栏工具进程仅在活动变化或有界健康检查时启动，读回后退出。空闲期间不保留该Node进程；监听不发起模型回合。没有通用跨宿主daemon或自动安装/开机启动。

Windows启动器优先使用配置解释器同目录的`pythonw.exe`，接口子进程不附着控制台；当前实测空闲只保留Python与metadata接口两个业务进程。缺少同目录pythonw时保留原解释器，不安装新运行时。

`examples/codex-recency-config.json` 是合成占位配置，不能直接启用。设备配置、授权记录、检查点和移动日志留在用户控制位置。版本、资源测量和未验证范围见 [验证记录](references/validation.md)。

核心说明在 `SKILL.md`；按需参考 `references/`。`examples/` 全部为虚构数据，`tests/` 为离线测试。部分原生操作在一个 Windows Codex desktop 环境有实际读回依据，覆盖面见 [验证记录](references/validation.md)；不能把单机实测或离线通过当成跨产品兼容认证。
