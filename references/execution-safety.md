# 执行、备份、并发与回退

## 写前
- 用原生查询固定目标账户、组与任务稳定 ID。核对用户批准的 plan digest 或有效持续策略 digest、清单 revision、当前标题/状态/原组，不能用标题匹配代替身份
- 在用户控制的独立输出位置保存方案、原值、时间、应用版本和原生导出。输出目录按本机明确选择，不携带另一设备绝对路径；不得放入公开共享位置
- 能备份正文时按风险选择必要范围，记录条数/校验和及恢复方法；避免无关敏感内容。官方备份可能不含云端数据或附件，写清覆盖面
- 检查备份可读与恢复入口可用。不能把在线 SQLite 主文件 copy 当一致备份；不读取受限内部目录，不安装常驻监听器
- 记录 operation_id、session_id、原组、目标组、原标题、期望 revision、执行状态。日志只含必要字段；原文不是默认审计材料

## 写入与幂等
使用官方原子接口/条件更新（若存在）；否则缩小到逐条可撤销操作。即使本技能自建锁，也只能互斥本技能实例，不能阻止宿主/同步客户端写入。UI 自动化不能消除竞态，观察到变化就停止。

先创建已批准且确实不存在的组，再按稳定 ID 移动。存在同名组时核对真实 ID 和语义，冲突不合并。已经在目标组是 no-op；不得更新时间戳制造伪变更。记录原生返回值并读回。远端超时/中断时查询 operation_id 或目标状态；无法确定结果不重复提交。

日志与离线文件写入采用临时文件、校验后原子替换，既有文件先留副本；不要把这些文件机制宣传为宿主事务。批次中部分成功要保留真实成功记录，不能把整体状态标记完成或锁定。

## 验证
逐项比较会话 ID、原/新组、标题；核对列表分页与总数。确认活动对象、原有组名与历史无意外变化。验证迁移后会话能打开、历史/附件可访问的范围，能力不足的部分记“未验证”。业务目录/历史产物默认完全不动。

## 回退
准备逐项 inverse：移回原组；只有本次新建、当前仍空且没有其他使用者的组，才考虑按已批准范围用原生入口删除。删除/恢复仍服从目标宿主及更高层权限规则，不能借“回退”扩大授权。

先确认目标还保持本次写入状态，再应用逆操作。如果他人/用户后续改过，发生版本冲突，或某组已有新内容，停止该项并报告；不能整库恢复覆盖新工作。不得自动解档、删除会话或启动 WorkBuddy selfheal。标题逆操作仅在明确批准的恢复范围内、当前标题仍等于本次写入值时才可用原生入口恢复。备份导入会覆盖新数据时，说明范围并单独获得明确批准。
