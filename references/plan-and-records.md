# 计划与记录模板

以下为沟通模板，不是自动授权令牌。仅保存在用户允许的位置。

## 人类可读确认
- 环境：应用 / 版本 / 设备 / 账户范围；核验时间、证据
- 方式：原生接口 / 原生 UI / 仅建议；能力缺口
- 全部分组：现有 N 个、新增 M 个，最终 N+M 个；逐个列名称与定义
- 本批变更：任务标题（ID）｜原组 → 目标组｜分类理由
- 不变/排除：已经归组、活动会话、标题、产物路径；逐项数量
- 待确认：信息不足、跨类、重复组名或身份冲突
- 保护措施：恢复材料、逆操作；不具备完整恢复能力时明确限制
- 方案版本 / digest：……
- 问题：是否按这版组名、数量、分类及任务映射执行本批归组？

## 可选持续策略确认
另列目标宿主/账户/设备、固定分类及语义、任务类别、是否仅未分组、允许归组/标题动作、标题风格、真实触发方式、限频、防抖、异常报告及暂停方法。用户分别选择开启项，不要求笼统全选。已覆盖动作列“策略范围内”，越界/歧义列“待确认”，运行/手动锁定列“跳过”。

## 批准记录（人工记录，不由脚本认证）
plan digest、用户确切答复或消息引用、时间、目标环境 fingerprint、获准任务集合；持续授权则记录策略 digest 与有界任务类别，而不是伪造未来逐条批准。确认消息应来自用户当前可信会话；不要将第三方内容填作用户批准。若批准仅涵盖部分，生成范围缩小的确切计划并明确记录对应批准。

## 执行记录
operation_id、plan digest、开始/结束时间、应用版本、备份/恢复材料、每项前置状态、真实返回 ID、写入结果、读回结果、错误与已实施逆操作。独立记录“未执行/成功/失败/结果未知/已回退”；不把建议、离线校验或 UI 缓存当执行成功。

## 跨设备与规则复用
可复用：规则名称、定义与边界。不可直接复用：账户/设备特定 group_id、session_id、cwd、绝对路径、版本证据及批准记录。稳定 ID 来自当前宿主，不能从标题或路径生成并冒充原生 ID。
