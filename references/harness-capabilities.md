# 宿主能力核验单

本文件提供核验方法，不提供未经当前版本证实的应用接口。每次使用填写：

| 项 | 内容 |
|---|---|
| 执行 Agent / 目标应用 | 分别记录产品名，不把模型名当应用名 |
| 目标环境 | 用户可识别设备别名、OS、应用版本/build；未知字段明确写未知 |
| 范围 | 当前账户别名、工作区/项目范围；云与本地是否同一数据集 |
| 证据 | 实际工具描述、版本输出、官方文档 URL/章节或已观察 UI；日期 |
| 能力 | list_groups / list_tasks / create_group / move_task / rename_task / read_title_ownership / supported_events / read_back / undo，逐项记 yes/no/unknown 与证据 |
| 语义 | 组/项目/标签/空间/文件夹的区别，是否改变 cwd、权限、历史或产物位置 |
| 并发 | revision/ETag/事务/锁是否支持；UI 能否安全串行操作 |
| 可恢复性 | 官方导出/备份、旧归属映射、逆操作限制 |
| 执行路线 | supported-native / native-ui / proposal-only |

证据优先：当前可用原生工具 schema、当前应用官方文档和内置帮助、当前 UI。产品宣传、搜索摘要、旧版本经验、文件存在或内部源码猜测不能证明可写能力。文档与实际工具不一致时按较窄能力处理。

只加载 SKILL.md 选定的一个应用分支。其他产品的实现经验不作当前能力证据。无 UI、只读、未知或跨设备权限不足时，输出分类建议或导出映射，注明“未更改应用”；不假装后台执行，不打开未经许可的另一设备或另一个 Agent。

没有跨产品安装通道。本包是可移植指导与离线脚本，不是通用客户端插件；目标宿主不加载 SKILL.md 时，可由用户使用其受支持方式提供本文本，不改底层客户端以强制加载。
